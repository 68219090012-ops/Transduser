# สรุปความรู้เรื่องเซ็นเซอร์เบื้องต้น

## 1. เซ็นเซอร์คืออะไร
- เซ็นเซอร์เป็นอุปกรณ์ที่ตรวจจับสภาวะแวดล้อมหรือสัญญาณจากภายนอกและแปลงเป็นข้อมูลไฟฟ้า
- ข้อมูลที่ได้สามารถนำไปใช้งานควบคุม อัตโนมัติ หรือส่งต่อให้ระบบคอมพิวเตอร์ประมวลผล

## 2. ประเภทของเซ็นเซอร์ทั่วไป
- เซ็นเซอร์วัดแสง (Light Sensor) เช่น LDR, photodiode
- เซ็นเซอร์วัดอุณหภูมิ (Temperature Sensor) เช่น DS18B20, LM35, DHT11/DHT22
- เซ็นเซอร์วัดความชื้น (Humidity Sensor) เช่น DHT11/DHT22
- เซ็นเซอร์วัดระยะทาง (Distance Sensor) เช่น ultrasonic, infrared
- เซ็นเซอร์วัดแรงดันหรือแรงสัมผัส (Pressure/Force Sensor)
- เซ็นเซอร์เคลื่อนไหวหรือสั่นสะเทือน (Motion/Vibration Sensor)
- เซ็นเซอร์แก๊สหรือควัน (Gas/Smoke Sensor)

## 3. หน่วยสัญญาณของเซ็นเซอร์
- Analog: ให้แรงดันหรือกระแสต่อเนื่องตามค่าที่วัดได้
- Digital: ให้ค่าที่กำหนดไว้ เช่น 0/1, I2C, SPI, UART
- ในไมโครคอนโทรลเลอร์ เช่น Arduino/ESP32 สามารถอ่านค่าแอนะล็อกผ่าน ADC

## 4. การเชื่อมต่อกับบอร์ดควบคุม
- ใช้สายสัญญาณเชื่อมต่อขา VCC, GND และขา output ของเซ็นเซอร์เข้ากับบอร์ด
- เซ็นเซอร์บางชนิดต้องการวงจรปรับสัญญาณหรือตัวต้านทานเพิ่ม เช่น pull-up resistor
- เซ็นเซอร์ดิจิทัลแบบ I2C ใช้สาย SDA/SCL ร่วม และแบบ SPI ใช้ MOSI/MISO/SCLK/CS

## 5. การใช้งานในโปรเจกต์
- เริ่มจากอ่านข้อมูลจากเซ็นเซอร์และแปลงเป็นค่าเข้าใจง่าย
- เขียนโค้ดเพื่ออ่านค่าเซ็นเซอร์เป็นรอบๆ แล้วประมวลผล
- นำข้อมูลไปใช้ควบคุมอุปกรณ์ เช่น เปิดไฟ ปรับพัดลม ส่งเตือน หรือเก็บค่าแบบล็อก

## 6. ข้อควรระวัง
- เชื่อมต่อสายให้ถูกขา VCC และ GND เสมอ
- ตรวจสอบแรงดันไฟฟ้าที่เซ็นเซอร์รองรับ
- เซ็นเซอร์บางตัวต้องใช้เวลารอสถานะให้เสถียรก่อนอ่านค่า
- อ่าน datasheet เพื่อดูวิธีใช้งานและขาเชื่อมต่ออย่างถูกต้อง

## 7. สรุป
- เซ็นเซอร์เป็นจุดเริ่มต้นสำคัญของระบบอิเล็กทรอนิกส์และ IoT
- เข้าใจประเภท สัญญาณ และการเชื่อมต่อพื้นฐานช่วยให้พัฒนาโปรเจกต์ได้ง่ายขึ้น
- การทดลองใช้งานกับเซ็นเซอร์แต่ละชนิดจะช่วยเพิ่มความคุ้นเคยและความเข้าใจในระบบควบคุม
