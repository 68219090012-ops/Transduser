# LAB03 DHT11

## ข้อมูลพื้นฐานของ DHT11

DHT11 เป็นเซ็นเซอร์วัดอุณหภูมิและความชื้นแบบดิจิทัล เหมาะสำหรับงานเรียนรู้และโปรเจกต์พื้นฐาน Arduino

- วัดอุณหภูมิได้ในช่วงประมาณ 0°C ถึง 50°C
- วัดความชื้นได้ในช่วงประมาณ 20% ถึง 90% RH
- ความแม่นยำประมาณ ±2°C สำหรับอุณหภูมิ
- ความแม่นยำประมาณ ±5% RH สำหรับความชื้น
- อัตราการอ่านข้อมูลซ้ำได้ประมาณ 1 ครั้งต่อวินาที (1Hz)
- ใช้สัญญาณแบบดิจิทัล (one-wire) เพื่อส่งข้อมูลไปยังบอร์ด

## ขาเชื่อมต่อของ DHT11

DHT11 ปกติจะมี 3 หรือ 4 ขา ดังนี้:

1. VCC: ต่อกับ 5V ของ Arduino
2. DATA: สัญญาณดิจิทัลไปยังขา Arduino
3. GND: ต่อกราวด์กับ Arduino
4. (ถ้ามี) NC หรือไม่ใช้งาน

> หมายเหตุ: ถ้าต่อแบบ 3 ขา ให้ต่อ VCC, DATA, GND โดยตรง ถ้าต่อแบบ 4 ขา ขาที่สี่อาจเป็น NC

## วงจรเชื่อมต่อเบื้องต้น

- ต่อขา VCC ของ DHT11 เข้าที่ 5V
- ต่อขา GND ของ DHT11 เข้าที่ GND
- ต่อขา DATA ของ DHT11 เข้าที่ขาดิจิทัล เช่น D2
- ใส่ตัวต้านทาน pull-up 4.7kΩ - 10kΩ ระหว่าง DATA กับ VCC เพื่อให้สัญญาณนิ่ง

## การใช้งานกับ Arduino

DHT11 ต้องใช้ไลบรารีเฉพาะ เช่น `DHT.h` และ `Adafruit_Sensor.h`

ตัวอย่างโค้ดพื้นฐาน:

```cpp
#include <Arduino.h>
#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("อ่านค่า DHT11 ไม่สำเร็จ");
    return;
  }

  Serial.print("อุณหภูมิ: ");
  Serial.print(temperature);
  Serial.println(" °C");

  Serial.print("ความชื้น: ");
  Serial.print(humidity);
  Serial.println(" %RH");

  delay(2000);
}
```

## ข้อควรระวัง

- ไม่ควรอ่านข้อมูลบ่อยเกินไป ควรเว้นระยะอย่างน้อย 1-2 วินาที
- ใช้แรงดันไฟเลี้ยง 5V เท่านั้นสำหรับ DHT11
- ตรวจสอบขั้วสัญญาณและสายให้ถูกต้องก่อนต่อ
