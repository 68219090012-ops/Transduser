# ชื่อโครงงาน

# ระบบตรวจจับเปลวไฟและเปิดพัดลมดูดควัน

ระบบตรวจจับเปลวไฟด้วยเซนเซอร์ KY-026 เมื่อพบเปลวไฟ จะสั่งงาน Relay เพื่อเปิดพัดลมดูดควันอัตโนมัติ และแสดงสถานะบนจอ LCD

---

# อุปกรณ์ที่ใช้

1. KY-026 Flame Sensor
2. Arduino UNO R3
3. LCD 16x2 I2C
4. Relay Module 5V

---

# หลักการทำงาน

1. KY-026 ตรวจจับเปลวไฟ
2. Arduino ประมวลผลข้อมูล
3. Relay ทำงาน สั่งเปิดพัดลมดูดควัน
4. พัดลมดูดควันทำงาน และแสดงสถานะบน LCD

---

# การต่อวงจร

## KY-026

- VCC → 5V
- GND → GND
- DO → D7

## LCD 16x2 I2C

- SDA → A4
- SCL → A5
- VCC → 5V
- GND → GND

## Relay Module

- IN → D8
- VCC → 5V
- GND → GND

## พัดลมดูดควัน (AC 220V)

เชื่อมต่อผ่าน Relay

- NO
- COM
- NC

---

# สีของสายไฟในแผนภาพ

- สีแดง = 5V
- สีดำ = GND
- สีเหลือง = สัญญาณ DO (D7)
- สีฟ้า = I2C (SDA/SCL)
- สีส้ม = สัญญาณ Relay (D8)

---

# ตารางการต่อวงจร KY-026

| KY-026 | Arduino |
|--------|---------|
| VCC | 5V |
| GND | GND |
| DO | D7 |

---

# ตารางการต่อวงจร LCD I2C

| LCD | Arduino |
|------|---------|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

---

# ตารางการต่อวงจร Relay

| Relay | Arduino |
|--------|---------|
| VCC | 5V |
| GND | GND |
| IN | D8 |

# คุณสมบัติเด่น

- ตรวจจับเปลวไฟได้รวดเร็ว
- เปิดพัดลมดูดควันอัตโนมัติ
- แสดงสถานะบนจอ LCD ชัดเจน
- วงจรง่าย ประหยัดค่าใช้จ่าย
- เหมาะสำหรับงานอุตสาหกรรมขนาดเล็ก

---

# การประยุกต์ใช้งาน

- โรงงานอุตสาหกรรม
- ห้องเชื่อม / งานโลหะ
- ห้องครัวเชิงพาณิชย์
- ห้องปฏิบัติการ
- ตู้ควบคุมไฟฟ้า

---

# ข้อควรระวัง

- Relay ควบคุมเฉพาะวงจร AC 220V
- ควรต่อสายไฟให้แน่นหนาและหุ้มฉนวน
- ติดตั้งเซนเซอร์ในตำแหน่งที่เหมาะสม
- ตรวจสอบระบบเป็นประจำ

> ⚠️ ระวังไฟฟ้า AC 220V
