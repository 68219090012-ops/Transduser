# โครงสร้างบอร์ด Arduino UNO R3 และขาใช้งาน

## 1. ภาพรวมของบอร์ด
- Arduino UNO R3 เป็นบอร์ดไมโครคอนโทรลเลอร์ยอดนิยมสำหรับผู้เริ่มต้น
- ใช้ชิป ATmega328P เป็นซีพียูหลัก
- มีพอร์ต USB Type-B สำหรับเชื่อมต่อกับคอมพิวเตอร์ และพอร์ต DC jack สำหรับจ่ายไฟภายนอก
- เหมาะสำหรับงานควบคุม เซ็นเซอร์ และการทำโปรเจกต์ IoT เบื้องต้น

## 2. ชิปหลักและส่วนประกอบสำคัญ
- ATmega328P: ไมโครคอนโทรลเลอร์หลัก
- ATmega16U2: ใช้เป็น USB-to-Serial converter สำหรับโปรแกรมและสื่อสาร
- Crystal oscillator 16MHz: ให้สัญญาณนาฬิกาแก่ไมโครคอนโทรลเลอร์
- Voltage regulator: จัดการแรงดันไฟฟ้า 5V และ 3.3V
- Power LED, L LED, TX/RX LED: ใช้บอกสถานะการทำงานและการสื่อสาร

## 3. ขาเชื่อมต่อไฟฟ้า
- VIN: รับแรงดันจากภายนอก 7-12V ถ้าต้องการใช้ตัวจ่ายไฟภายนอก
- 5V: แรงดัน 5V ที่ใช้จ่ายให้กับบอร์ดและวงจรภายนอก
- 3.3V: แรงดัน 3.3V สำหรับเซ็นเซอร์หรือโมดูลที่ต้องการ
- GND: ขาที่ต่อกราวด์ มีหลายขาในบอร์ด
- RESET: กดเพื่อตั้งค่าไมโครคอนโทรลเลอร์ให้เริ่มทำงานใหม่

## 4. ขา I/O ดิจิทัล
- ขาดิจิทัล D0-D13 รวม 14 ขา
- ขา D0 (RX) และ D1 (TX) ใช้สำหรับการสื่อสาร Serial
- ขา D2-D13 ใช้งานเป็น input/output ทั่วไป
- ขาที่สามารถใช้ PWM ได้: D3, D5, D6, D9, D10, D11
- ขา D10, D11, D12, D13 ใช้เป็น SPI interface ได้เมื่อใช้งานกับโมดูล SPI

## 5. ขาแอนะล็อก
- A0-A5 มี 6 ขาแอนะล็อกสำหรับอ่านค่าสัญญาณต่อเนื่อง
- สามารถใช้เป็นขาดิจิทัลเพิ่มเติมได้ (D14-D19)
- เหมาะสำหรับอ่านเซ็นเซอร์ เช่น อุณหภูมิ แสง หรือแรงดัน

## 6. พอร์ตสื่อสาร
- Serial (UART): ใช้ขา D0 (RX) และ D1 (TX)
- I2C: ใช้ขา SDA (A4) และ SCL (A5)
- SPI: ใช้ขา SCK (D13), MISO (D12), MOSI (D11), SS (D10)
- USB: เชื่อมต่อกับคอมพิวเตอร์เพื่ออัพโหลดโปรแกรมและพูดคุยผ่าน Serial Monitor

## 7. พลังงานและการจ่ายไฟ
- สามารถจ่ายไฟด้วย USB 5V หรือผ่าน DC jack 7-12V
- หากจ่ายไฟจาก VIN หรือ DC jack จะผ่านวงจร regulator เพื่อจ่าย 5V ให้บอร์ด
- มี jumper หรือ switch สำหรับเลือกแหล่งจ่ายไฟบางรุ่น

## 8. การใช้งานพื้นฐาน
- เชื่อมต่อบอร์ดเข้ากับคอมพิวเตอร์ด้วยสาย USB
- เปิด Arduino IDE หรือ PlatformIO เพื่อเลือกบอร์ดและพอร์ต COM
- อัพโหลดสเก็ตช์ตัวอย่าง เช่น Blink เพื่อทดสอบ LED บนขา D13
- อ่านค่าเซ็นเซอร์จากขาแอนะล็อก หรือควบคุมมอเตอร์ด้วยขา PWM

## 9. ตัวอย่างการใช้งาน DHT11 อ่านอุณหภูมิและความชื้น
- ขา DATA ของ DHT11 ต่อกับขา D4 ของ Arduino
- ขา VCC ของ DHT11 ต่อกับ 5V
- ขา GND ของ DHT11 ต่อกับ GND
- ใส่ตัวต้านทาน pull-up 4.7kΩ - 10kΩ ระหว่าง DATA และ VCC

ตัวอย่างโค้ดสำหรับอ่านค่า DHT11 และส่งค่าไปยัง Serial Monitor:

```cpp
#include <Arduino.h>
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("อ่านค่า DHT11 ไม่สำเร็จ");
  } else {
    Serial.print("อุณหภูมิ: ");
    Serial.print(temperature);
    Serial.println(" °C");

    Serial.print("ความชื้น: ");
    Serial.print(humidity);
    Serial.println(" %RH");
  }

  delay(2000);
}
```

## 10. ข้อควรระวัง
- ระวังแรงดันไฟฟ้าที่จ่ายเข้า VIN และ 5V ไม่เกินค่าที่บอร์ดรองรับ
- ห้ามต่อขา I/O เข้ากับแรงดันที่สูงกว่า 5V โดยตรง
- ก่อนเชื่อมต่อสายกับเซ็นเซอร์หรือมอเตอร์ ควรตรวจสอบขั้วและแรงดันให้ถูกต้อง

## 10. สรุป
- Arduino UNO R3 มีขาใช้งานหลากหลาย ทั้งดิจิทัล แอนะล็อก และสื่อสาร
- เหมาะสำหรับผู้เริ่มต้นเรียนรู้ไมโครคอนโทรลเลอร์และการพัฒนาโปรเจกต์อิเล็กทรอนิกส์
- เข้าใจโครงสร้างและขาใช้งานช่วยให้ต่อวงจรได้ถูกต้องและปลอดภัย
