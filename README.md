# Transduser

โปรเจกต์นี้เป็นโปรเจกต์ Arduino UNO ที่พัฒนาโดยใช้ PlatformIO เพื่อทดลองเขียนโค้ดและอัปโหลดลงบอร์ดแบบง่าย ๆ

## วัตถุประสงค์
- เรียนรู้การสร้างโปรเจกต์ Arduino ด้วย PlatformIO
- ทดสอบการ build และ upload โค้ดลงบอร์ด Arduino UNO
- เป็นฐานสำหรับพัฒนาโปรเจกต์ที่เกี่ยวกับเซ็นเซอร์หรืออุปกรณ์รับ-ส่งสัญญาณต่อไป

## อุปกรณ์ที่ใช้
- Arduino UNO
- สาย USB สำหรับเชื่อมต่อกับคอมพิวเตอร์
- คอมพิวเตอร์ที่ติดตั้ง PlatformIO แล้ว

## การเตรียมตัว
1. ติดตั้ง PlatformIO IDE บน VS Code หรือใช้ PlatformIO Core
2. เปิดโฟลเดอร์โปรเจกต์นี้ใน VS Code
3. ตรวจสอบว่าเลือกบอร์ดเป็น Arduino UNO แล้ว

## คำสั่งที่ใช้บ่อย
- build โปรเจกต์:
  - `pio run`
- อัปโหลดโค้ดลงบอร์ด:
  - `pio run -t upload`
- เปิด Monitor สำหรับดู output:
  - `pio device monitor`

## โครงสร้างโปรเจกต์
- `src/main.cpp` : โค้ดหลักของโปรเจกต์
- `platformio.ini` : ไฟล์ตั้งค่าบอร์ดและ framework
- `include/` : ไฟล์ header ที่ใช้ในโปรเจกต์
- `lib/` : ไลบรารีเพิ่มเติม
- `test/` : ไฟล์ทดสอบและเอกสารประกอบ

## สถานะปัจจุบันของโปรเจกต์
โค้ดในโปรเจกต์ปัจจุบันจะทำให้ LED บนบอร์ด Arduino UNO กระพริบทุก 0.5 วินาที ซึ่งเหมาะสำหรับทดสอบว่าโปรเจกต์ build และ upload ได้ถูกต้อง

## หมายเหตุ
หากต้องการพัฒนาโปรเจกต์นี้ต่อเป็นระบบเซ็นเซอร์หรือ IoT คุณสามารถเพิ่มไลบรารีและโค้ดในส่วน `src/` ได้ตามต้องการ
